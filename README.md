# Security Drill 2026

## Drill Charter

This repository is a **disposable scratch workspace** for the quarterly tabletop security drill.

- **Purpose:** rehearse the full end-to-end change flow (branch → pull request → squash merge → issue follow-ups) in a low-risk environment.
- **Lifecycle:** the workspace is temporary and will be disposed of after the exercise completes.
- **Scope:** no production code, secrets, or real infrastructure belong here.

> ⚠️ This workspace is **disposable after the exercise** and should not be used for anything durable.
